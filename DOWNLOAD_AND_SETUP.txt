  1. Create a new text file named ".gitignore"
  2. Add these lines to it:

     .vscode/
     *.egg-info/
     dist/

   touch .env

2. Open it and add your OpenAI API key:
   cat > .env << 'DOTENV'

Problem: Can't see data/golden_eval_set.json after download
Solution: Make sure you extracted the ZIP correctly. All folders should be visible.

Problem: .gitignore file doesn't appear
Solution: Hidden files. Enable viewing hidden files or create manually (see Step 2).

Problem: "ModuleNotFoundError" when running test_agent.py
Solution: pip install -r requirements.txt

Problem: "OPENAI_API_KEY not found" error
Solution: echo $OPENAI_API_KEY (check if set)
         cat .env (verify .env file exists and has key)

Problem: Can't push to GitHub
Solution: Generate Personal Access Token at GitHub → Settings → Developer settings
         Use that token when asked for password during git push

Problem: Repository shows as private but you want public
Solution: GitHub → Repository Settings → Danger Zone → Change to Public
